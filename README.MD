# Librería Online

## Descripción del Proyecto
Librería Online es un sistema web para visualizar y gestionar el catálogo de una librería. Permite la visualización de libros y autores, y ha sido adaptado para funcionar como una página web estática. Esto permite que el proyecto pueda ser desplegado fácilmente en GitHub Pages o cualquier otro servicio de alojamiento estático, conservando su diseño original y simulando las interacciones mediante JavaScript. Desarrollado originalmente por Albert A. Peguero Garcia.

## Características
- **Interfaz Moderna**: Diseño atractivo y responsivo utilizando HTML, CSS, JavaScript y componentes de Bootstrap.
- **Catálogo de Libros y Autores**: Visualización del listado de libros disponibles (con precios y tipos) y autores destacados.
- **Simulación de Gestión (CRUD)**: Formularios para agregar nuevos libros y autores, con alertas de interacción simuladas mediante JavaScript.
- **Formulario de Contacto**: Sección integrada para enviar comentarios o solicitudes (interacción simulada).
- **Compatibilidad con GitHub Pages**: El proyecto está libre de dependencias de backend (como PHP o bases de datos), lo que garantiza su despliegue sin problemas en entornos estáticos.
